How to export PNG locally

  1. Open this file in a browser (double-click docs/flowchart.html).
  2. Right-click the rendered diagram and choose "Save image as..." or use browser devtools → "Capture node screenshot".
  3. Or generate a PNG via Mermaid CLI (requires Node.js):
npx @mermaid-js/mermaid-cli -i docs/flowchart.mmd -o docs/flowchart.png --width 1200
# Or install globally:
# npm i -g @mermaid-js/mermaid-cli
# mmdc -i docs/flowchart.mmd -o docs/flowchart.png
